# Pair Day Maker

캐릭터 이미지와 문구를 넣어 커플(페어) 기념일 이미지를 PNG로 만드는 웹 도구입니다.
서버 없이 브라우저 안에서만 동작하므로 GitHub Pages에 그대로 올려 쓸 수 있어요.

## 기능

- **템플릿 타입 3종**
  - A. 월페이퍼: 두 캐릭터가 함께 있는 16:9 일러스트 1장
  - B. 두상: 캐릭터별 두상 이미지 2장
  - C. 헤더: 3:1 헤더 일러스트 1장 (1500×500 권장)
- **테마 5종**: 미니멀 · 시네마 · 레터 · 매거진 · 드리미. 타입마다 각각 다른 레이아웃이 있어요.
- **디데이**: 시작일 = 1일 기준 자동 계산, 또는 숫자 직접 입력. `D+N`, `N일째` 표기를 각각 켜고 끌 수 있어요.
- **텍스트**: 페어명, 캐릭터 이름 2개, 이름 사이 기호, 라벨, 캐치프레이즈, 캐릭터 대사 2개, 시작일
  - 각 항목 표시/숨김, 드래그 이동, 회전·크기 조절
  - 폰트, 굵기, 크기, 색, 자간, 행간, 정렬, 외곽선, 그림자, 투명도
  - 자리표시자: `{days}` `{date}` `{pair}` `{name1}` `{name2}`
- **이미지 프레임**: 확대·축소, 위치 이동(드래그), 회전, 좌우 반전, 꽉 채우기/전체 보이기
  - 모양: 사각 · 둥근 사각 · 원형 · 아치 · 육각형 · 마름모 · 하트
  - 테두리(두께·색·간격), 폴라로이드, 그림자
- **배경**: 테마 기본 · 단색 · 그라데이션(선형/원형) · 이미지(확대·위치·흐림·덮는 색)
- **스티커**: 이미지 스티커, 텍스트 스티커, 기호/이모지 빠른 추가. 순서 변경·복제·반전
- **폰트**: Pretendard 기본, Google Fonts 추천 목록 + 이름 직접 입력
- **저장**: 1920×1080 기준 0.5× ~ 2× (최대 3840×2160) PNG
- **기타**: 되돌리기/다시 실행, 브라우저 자동 저장, 프로젝트 백업 파일(.json) 저장·불러오기, 파일 끌어다 놓기·붙여넣기

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다 (예: `pair-day-maker`). Public으로 만들어야 무료 Pages를 쓸 수 있어요.
2. 이 폴더의 파일을 **폴더 구조 그대로** 저장소 최상단에 올립니다.
   - 웹에서: 저장소 → **Add file → Upload files** → 압축을 푼 폴더 안의 내용물(`index.html`, `css`, `js`, `vendor`, `README.md`)을 끌어다 놓고 Commit
3. 저장소 → **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: `main` / `/(root)` 선택 후 Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속할 수 있어요.

> 로컬에서 확인하려면 `index.html`을 더블클릭해서 열어도 동작합니다. (폰트는 인터넷 연결이 필요해요)

## 파일 구조

```
index.html          화면 구성
css/style.css       편집기 스타일
js/app.js           편집기 로직 (캔버스, 입력, 내보내기)
js/themes.js        테마·레이아웃 정의 ← 디자인 수정은 여기서
js/fonts.js         폰트 목록·로딩
js/store.js         브라우저 자동 저장
vendor/konva.min.js 캔버스 라이브러리 (Konva 9, MIT)
```

## 테마 수정·추가

`js/themes.js`에서 테마 하나는 `palette`(색), `bg`(기본 배경), `defaults`(라벨·구분기호 기본 문구), `layouts.A/B/C`로 구성돼요.
좌표는 모두 1920×1080 캔버스 기준입니다.

- `slots`: 캐릭터 이미지 프레임 위치·크기·모양
- `decor`: 장식(사각형, 선, 원, 반짝이, 고정 글자)
- `texts`: 텍스트 기본 위치·스타일 (`x`는 `align` 기준점, `anchorY`로 세로 기준점)
- `rows`: 길이가 바뀌어도 겹치지 않게 가로로 이어 붙는 텍스트 묶음

새 테마는 기존 테마 객체를 복사해 `id`·`name`을 바꾸고 파일 맨 아래 배열에 추가하면 됩니다.

## 참고

- 이미지는 업로드 파일만 지원해요. 외부 URL 이미지는 브라우저 보안 정책 때문에 PNG 저장이 막힙니다.
- 업로드 이미지는 긴 변 4096px로 자동 축소돼요.
- 자동 저장은 브라우저(IndexedDB)에만 저장됩니다. 다른 기기로 옮기려면 백업 파일을 쓰세요.
- iOS Safari에서 PNG가 새 탭으로 열리면 모바일 전용 **공유 · 사진에 저장** 버튼을 써 주세요.
